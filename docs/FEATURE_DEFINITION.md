# 📋 CutStudio v5.0 - 기능 정의서 (Feature Definition Document)

## 1. 제품 비전

### 1.1 문제 정의
**현재 교육 콘텐츠 제작자들이 겪는 문제:**
- 📺 긴 강의 영상에서 핵심 부분만 추출하기 어려움
- 👥 여러 화자가 있는 영상에서 특정 화자 부분만 편집하기 복잡함
- ⏰ 수동 편집에 너무 많은 시간 소요 (평균 1시간 영상 = 5시간 편집)
- 💰 전문 편집 도구는 비싸고 학습 곡선이 가파름
- 📝 자막 생성과 요약 작업이 번거로움

### 1.2 솔루션
**CutStudio가 제공하는 가치:**
- 🤖 AI가 자동으로 화자를 구분하고 중요 구간을 식별
- ✂️ 원클릭으로 불필요한 구간 제거
- 📝 자동 자막 생성 및 핵심 내용 요약
- 🚀 편집 시간을 5시간 → 30분으로 단축
- 💡 누구나 쉽게 사용할 수 있는 직관적 인터페이스

## 2. 타겟 사용자

### 2.1 주요 사용자 그룹

| 사용자 그룹 | 특징 | 주요 니즈 | 우선순위 |
|------------|------|-----------|---------|
| **온라인 강사** | - 정기적으로 강의 영상 제작<br>- 1-2시간 길이 영상 | - 핵심 내용만 추출<br>- 화자별 구분 | P0 |
| **교육 기관** | - 대량의 강의 영상 보유<br>- 아카이브 필요 | - 배치 처리<br>- 자동 요약 | P0 |
| **기업 교육팀** | - 내부 교육 자료 제작<br>- 회의 녹화 편집 | - 보안<br>- 협업 기능 | P1 |
| **개인 크리에이터** | - YouTube 교육 콘텐츠<br>- 짧은 클립 제작 | - 빠른 편집<br>- 다양한 포맷 | P1 |
| **학생/연구원** | - 강의 녹음 정리<br>- 세미나 요약 | - 저렴한 가격<br>- 텍스트 추출 | P2 |

### 2.2 사용자 페르소나

**Primary Persona: 김교수 (온라인 강사)**
- 나이: 35세
- 직업: 대학 강사 / 온라인 교육 플랫폼 강사
- 기술 수준: 중급 (기본 편집 도구 사용 가능)
- 목표: 2시간 강의를 15분 핵심 요약 영상으로 만들기
- 고민: "편집에 시간을 너무 많이 써서 콘텐츠 제작이 느려요"

## 3. 핵심 기능 정의

### 3.1 기능 계층 구조

```
CutStudio
├── 📥 입력 (Input)
│   ├── 파일 업로드
│   ├── YouTube 다운로드
│   └── 클라우드 연동
├── 🔍 분석 (Analysis)
│   ├── 화자 감지
│   ├── 음성 인식
│   ├── 장면 전환 감지
│   └── 중요도 스코어링
├── ✂️ 편집 (Editing)
│   ├── 스마트 컷
│   ├── 타임라인 편집
│   ├── 화자별 추출
│   └── 무음 구간 제거
├── 🤖 AI 처리 (AI Processing)
│   ├── 자동 자막
│   ├── 내용 요약
│   ├── 키워드 추출
│   └── 하이라이트 생성
└── 📤 출력 (Output)
    ├── 비디오 내보내기
    ├── 자막 파일
    ├── 요약 문서
    └── 타임스탬프
```

### 3.2 상세 기능 명세

#### F001: 비디오 업로드 및 관리
**설명**: 사용자가 편집할 비디오를 시스템에 업로드

**상세 요구사항**:
- 지원 형식: MP4, AVI, MOV, MKV, WEBM
- 최대 크기: 2GB (확장 가능)
- 멀티 파일 업로드 지원
- 업로드 진행률 표시
- 썸네일 자동 생성

**인수 조건**:
- [ ] 2GB MP4 파일 업로드 성공
- [ ] 업로드 중 취소 가능
- [ ] 중복 파일 감지

---

#### F002: 화자 감지 및 분리
**설명**: AI가 영상에서 여러 화자를 자동으로 구분

**상세 요구사항**:
- 최대 10명 화자 구분
- 화자별 타임라인 생성
- 화자 이름 수동 지정 가능
- 정확도 85% 이상
- 처리 시간: 영상 길이의 30% 이내

**인수 조건**:
- [ ] 2명 화자 영상에서 90% 정확도
- [ ] 5명 화자 영상에서 80% 정확도
- [ ] 화자별 색상 구분 표시

---

#### F003: 음성 인식 및 자막 생성
**설명**: 음성을 텍스트로 변환하고 자막 생성

**상세 요구사항**:
- 한국어/영어 자동 감지
- 정확도 95% 이상 (명확한 음성 기준)
- 타임스탬프 동기화
- SRT, VTT 형식 지원
- 수동 편집 가능

**인수 조건**:
- [ ] 한국어 강의 95% 정확도
- [ ] 영어 강의 95% 정확도
- [ ] SRT 파일 다운로드

---

#### F004: 스마트 편집 (Smart Cut)
**설명**: AI가 자동으로 불필요한 부분을 제거

**제거 대상**:
- 무음 구간 (3초 이상)
- 음... 어... 같은 간투사
- 반복 설명 구간
- 화면 전환 중 빈 구간

**옵션**:
- 공격성 레벨 (보수적/균형/공격적)
- 최소 클립 길이 설정
- 수동 복원 가능

**인수 조건**:
- [ ] 무음 구간 100% 감지
- [ ] 편집 전후 비교 미리보기
- [ ] 원본 대비 30% 길이 단축

---

#### F005: AI 요약 및 하이라이트
**설명**: 영상 내용을 텍스트로 요약하고 핵심 구간 표시

**요약 기능**:
- 전체 요약 (500자)
- 챕터별 요약
- 화자별 핵심 발언
- 키워드 추출 (10개)

**하이라이트**:
- 중요도 점수 계산
- 5분 하이라이트 영상 생성
- 타임스탬프 목차 생성

**인수 조건**:
- [ ] 1시간 영상 → 500자 요약
- [ ] 핵심 키워드 10개 추출
- [ ] 5분 하이라이트 자동 생성

---

#### F006: 타임라인 편집기
**설명**: 시각적 타임라인에서 직접 편집

**기능**:
- 드래그 앤 드롭 편집
- 멀티 트랙 지원
- 실시간 미리보기
- 자르기/붙이기/복사
- 효과 적용 (페이드, 전환)

**인수 조건**:
- [ ] 10초 이내 미리보기 로딩
- [ ] 실시간 편집 반영
- [ ] Undo/Redo 지원

---

#### F007: 배치 처리
**설명**: 여러 영상을 한 번에 처리

**기능**:
- 폴더 단위 업로드
- 동일 설정 일괄 적용
- 처리 큐 관리
- 백그라운드 처리

**인수 조건**:
- [ ] 10개 파일 동시 처리
- [ ] 처리 상태 실시간 업데이트
- [ ] 실패 시 재시도

---

#### F008: 내보내기 및 공유
**설명**: 편집된 영상을 다양한 형식으로 내보내기

**출력 형식**:
- 비디오: MP4, WEBM, AVI
- 오디오: MP3, WAV
- 자막: SRT, VTT, TXT
- 문서: PDF 요약본

**공유 옵션**:
- 직접 다운로드
- 클라우드 업로드
- 링크 공유
- YouTube 업로드

**인수 조건**:
- [ ] 1080p MP4 내보내기
- [ ] 자막 임베딩
- [ ] 메타데이터 보존

## 6. 성공 지표 (Success Metrics)

### 6.1 기능별 KPI

| 기능 | 측정 지표 | 목표 | 측정 방법 |
|------|----------|------|-----------|
| **화자 감지** | 정확도 | 85% | F1 Score |
| **음성 인식** | 정확도 | 95% | WER (Word Error Rate) |
| **스마트 컷** | 시간 단축 | 30% | 원본 대비 길이 |
| **처리 속도** | 처리 시간 | 실시간의 30% | 처리시간/영상길이 |
| **사용자 만족도** | NPS | 50+ | 설문조사 |

### 6.2 비즈니스 지표

- **MAU (Monthly Active Users)**: 1,000명
- **평균 처리 영상 수**: 10개/사용자/월
- **평균 편집 시간 단축**: 70%
- **유료 전환율**: 10%

## 7. 기술적 제약사항

### 7.1 성능 요구사항
- 최대 동시 사용자: 100명
- 평균 응답 시간: < 1초
- 비디오 처리: < 실시간의 50%
- 메모리 사용: < 2GB/세션

### 7.2 제한사항
- 브라우저: Chrome, Edge, Safari 최신 2개 버전
- 인터넷 속도: 최소 10Mbps
- 비디오 코덱: H.264, H.265
- 오디오: 44.1kHz 이상

## 9. 사용자 스토리

### 9.1 핵심 사용자 스토리

**US001**: 강사로서, 2시간 강의를 15분 요약 영상으로 만들고 싶다
```
Given: 2시간 강의 영상이 있을 때
When: 스마트 컷 기능을 실행하면
Then: 핵심 내용만 담긴 15분 영상이 생성된다
```

**US002**: 교육팀장으로서, 여러 강사의 발표를 구분하여 편집하고 싶다
```
Given: 5명이 발표한 세미나 영상이 있을 때
When: 화자 감지를 실행하면
Then: 각 화자별로 구분된 타임라인이 생성된다
```

**US003**: 학생으로서, 강의 내용을 텍스트로 정리하고 싶다
```
Given: 1시간 강의 영상이 있을 때
When: 음성 인식과 요약을 실행하면
Then: 전체 자막과 핵심 요약이 생성된다
```
