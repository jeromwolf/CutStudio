## 1. 제품 개요

### 1.1 제품명
**CutStudio v5.0** - AI 기반 교육 영상 자동 편집 도구

### 1.2 제품 비전
> "교육 영상 편집을 10시간에서 15분으로 단축하는 AI 자동화 도구"

### 1.3 목표 사용자
| 구분 | 대상 | 규모 | 페인포인트 |
|------|------|------|------------|

| **Secondary** | 교육 기관 | 2,000개 | 대량 영상 처리 |
| **Tertiary** | 교육 유튜버 | 1,000명 | 자막 생성 번거로움 |

### 1.4 핵심 가치 제안 (Value Proposition)
```
AS-IS (현재)
- 2시간 영상 편집에 10시간 소요
- 화자 구분 수동 작업
- 자막 생성 외주 의뢰
- 월 $2,000 편집 비용

- 2시간 영상 15분에 처리
```

## 4. 기능 명세

### 4.1 핵심 기능 상세

#### F1: 화자 감지 및 분리
```yaml
설명: AI가 영상에서 여러 화자를 자동으로 구분
입력:
  - 비디오 파일 (MP4/AVI/MOV)
  - 최대 화자 수 (2-10명)
처리:
  - PyAnnote 모델로 화자 분리
  - 음성 특징 추출
  - 클러스터링
출력:
  - 화자별 타임라인
  - 화자별 발화 시간
  - 신뢰도 점수
성능:
  - 처리 시간: 영상 길이의 30%
  - 정확도: 85% 이상
  - 메모리: 2GB 이하
```

#### F2: 스마트 컷 (Smart Cut)
```yaml
설명: 불필요한 부분을 자동으로 제거
대상:
  - 침묵 (2초 이상)
  - 간투사 (음, 어, 그)
  - 반복 구간
모드:
  - Conservative: 3초 이상 침묵만
  - Balanced: 2초 침묵 + 간투사
  - Aggressive: 1초 침묵 + 모든 간투사
출력:
  - 편집된 영상
  - 제거 구간 리스트
  - 시간 단축 통계
```

#### F3: 음성 인식 (Speech-to-Text)
```yaml
설명: Whisper로 음성을 텍스트로 변환
모델:
  - OpenAI Whisper base
  - 로컬 실행
언어:
  - 자동 감지
  - 한국어, 영어, 일본어, 중국어
출력:
  - 전체 대본
  - 타임스탬프 포함 텍스트
  - SRT/VTT 자막 파일
정확도:
  - 한국어: 95%
  - 영어: 97%
```

## 8. Post-MVP 교육 특화 기능

### 8.1 강의 최적화 기능 (v5.1)

#### 질문 구간 자동 감지
- **설명**: "질문 있습니다", "궁금한게 있는데" 등 자동 감지
- **가치**: 강사가 Q&A 섹션 쉽게 찾기
- **예상 개발**: 1주

#### 중요 내용 자동 하이라이트
- **설명**: "시험에 나옵니다", "중요합니다" 구간 자동 표시
- **가치**: 학생들이 핵심 내용 빠르게 복습
- **예상 개발**: 1주

#### 판서 화면 자동 캡처
- **설명**: 칠판/화이트보드 내용 자동 스크린샷
- **가치**: PDF 강의 자료 자동 생성
- **예상 개발**: 2주

### 8.2 학습 효율 개선 (v5.2)

#### 반복 설명 통합
- **설명**: 같은 내용 여러 번 설명한 부분 하나로 정리
- **가치**: 복습 시간 단축
- **예상 개발**: 2주

#### 배속 재생 최적화
- **설명**: 구간별 최적 재생 속도 자동 설정
- **가치**: 중요 부분은 정속, 반복 부분은 2배속
- **예상 개발**: 1주

#### 학습 노트 자동 생성
- **설명**: 시간대별 핵심 내용 정리 노트
- **가치**: 학생들 필기 부담 감소
- **예상 개발**: 2주

### 8.3 교육 기관 특화 (v5.3)

#### 수업 시간표 연동
- **설명**: 시간표에 따라 자동 영상 분류
- **가치**: 과목별 자동 정리
- **예상 개발**: 2주

#### 학생 참여도 분석
- **설명**: 질문 빈도, 집중도 측정
- **가치**: 수업 개선 인사이트
- **예상 개발**: 3주

#### 과제 피드백 영상 도구
- **설명**: 과제별 개인 피드백 영상 일괄 생성
- **가치**: 개인화된 피드백 제공
